TurboWarp HTTP Server React

This extension describes React islands for HTML responses produced by turbowarp-http-server and turbowarp-html.

Blocks

  • register React component [COMPONENT] from [MODULE]
  • React island [COMPONENT] at [MOUNT_ID] props [PROPS_JSON]
  • React island HTML [COMPONENT] at [MOUNT_ID] props [PROPS_JSON]
  • React component registry JSON

MVP boundary

The extension returns descriptors and HTML fragments. React, React DOM, MUI, hooks, CSS, hydration, and Vite dev/build integration belong to the application bundle.

Descriptor shape

{
  "kind": "react-island",
  "version": 1,
  "component": "Counter",
  "mountId": "counter-root",
  "props": {"initialCount": 0}
}
